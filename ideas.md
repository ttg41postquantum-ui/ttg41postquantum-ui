# Design Direction: AIRCC Author Guide

## Context

The supplied document is a formal manuscript template rather than a conventional research article. The web experience therefore prioritizes **reference usability, source fidelity, and editorial clarity** over promotional storytelling.

## Selected Direction: Contemporary Editorial Documentation

The chosen design combines a scholarly paper surface with a modern documentation shell. A deep navy header and hero establish hierarchy, while a warm white paper canvas keeps long-form reading comfortable. Copper accents identify section numbers, calls to action, and key requirements without overwhelming the source material.

| Element | Direction |
|---|---|
| Primary color | Deep navy for institutional structure |
| Accent color | Warm copper for restrained emphasis |
| Reading surface | Warm white with subtle paper contrast |
| Display typography | Garamond/Georgia-style serif |
| Manuscript typography | Times New Roman |
| Interface typography | Arial/Helvetica sans serif |
| Layout | Sticky contents rail plus centred paper sheet |
| Interaction | Anchor navigation, source download, official links |

## Responsive Behavior

Desktop layouts use a sticky table of contents beside the manuscript. On smaller screens, the paper becomes a full-width reading surface and the header retains the primary download action. Wide formatting tables scroll horizontally rather than compressing into unreadable columns.

## Accessibility and Print

Semantic headings mirror the source numbering, navigation regions are labelled, external links state their purpose, and decorative geometry is hidden from assistive technology. The print stylesheet removes the site header, hero, sidebar, call-to-action section, and footer so the paper content can be printed cleanly.
